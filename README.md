# Roast Me — Android downloads

This repository only hosts release files (APKs) for **Roast Me**, a little app that
roasts you into getting your work done. The source code is not here.

## Install
1. Open the latest release under **Releases** and download `roast-me-<version>.apk`.
2. Open the file on your Android phone. If asked, allow "Install unknown apps" for your browser or file manager.
3. Optional: check the file's SHA-256 against the one listed in the release notes.

## Privacy
Roast Me works fully offline. It has no accounts, no ads, no analytics and sends no data
off your phone. Your streak and settings are stored only on the device.

## Heads-up
Some modes (especially **Bhai**) use strong Hindi/Hinglish slang and profanity. 18+.
